# Richfield Connect — Powered by GritSim AI

A production-grade, cross-platform mobile ecosystem unifying Students, Alumni, Business Recruiters, and Administrators into a single trusted institutional network for the Richfield and AAA community.

## About GritSim AI
**GritSim AI** builds intelligent institutional infrastructure focused on **Graduate Readiness, Industry Transition, and Talent Matching (GRIT)**. Richfield Connect is architected to eliminate the graduate-opportunity gap through context-aware AI coaching, cryptographic identity verification, and role-differentiated engagement.

## System Architecture & Technology Choices
- **Frontend Runtime**: React Native 0.81 with React Native Web interoperability
- **Identity & Security**: Firebase Authentication v2 with custom claims & App Check
- **Database Engine**: Cloud Firestore with granular, field-level POPIA visibility controls
- **Asynchronous Media**: Google Cloud Transcoder for 720p H.264 video compression & thumbnail generation
- **AI & NLP Services**: Google Gemini 1.5 Flash for contextual coaching and automated CV skills parsing

## Role-Based Access Control (RBAC)
- **Student**: Strict institutional domain boundary enforcement (@richfield.ac.za, @aaa.ac.za).
- **Alumni**: Zero-knowledge verification against the institutional alumni registry using SHA-256 cryptographic hashing.
- **Business**: Dual-phase onboarding requiring formal administrative review before platform activation.
- **Administrator**: Dedicated moderation console for user governance and institutional broadcasts.

## Compliance & Privacy
Engineered in strict compliance with the South African **Protection of Personal Information Act (POPIA)** featuring user-controlled field visibility (Public, Connections, Private).
